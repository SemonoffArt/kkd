# Проект корпуса крупного дробления (ККД)

   ![](images/screenshot1.png)

## Описание проекта

Проект представляет собой систему автоматизации корпуса крупного дробления, реализованную на базе контроллера Siemens S7-1500 в TIA Portal v16. Система предназначена для управления технологическим процессом дробления горной массы, включая контроль и мониторинг работы дробильного оборудования, конвейерных линий и вспомогательных систем.

## Основные функции системы

- Управление дробильным оборудованием
- Контроль работы конвейерных линий
- Мониторинг параметров процесса
- Аварийная сигнализация и защита
- Сбор и архивация данных
- Взаимодействие с SCADA-системой FLS ECS

## Технические характеристики

- Контроллер: Siemens S7-1500
- Среда разработки: TIA Portal V16
- Язык программирования: LAD/FBD/SCL
- Протоколы связи: PROFINET
- Уровень автоматизации: АСУ ТП
- Количество сигналов ввода/вывода: 126
- SCADA-система: FLS ECS

## Оборудование

### Конвейерные линии

- CV300 (с частотно-регулируемым приводом INVT GOODRIVE)
- CV180 (с частотно-регулируемым приводом INVT GOODRIVE)
- CV120 (с частотно-регулируемым приводом INVT GOODRIVE)
- Магнит OV190

### Дробильное оборудование

- Питатель BF110 (с частотно-регулируемым приводом Schneider Altivar ATV)
- Грохот SC130 (с частотно-регулируемым приводом Schneider Altivar ATV)
- Щековая дробилка CR150

### Аспирация и отопление

- 6 насосов
- 2 задвижки
- ультразвуковой уровнемер
- PID регулятор уровня в баке

### Системы управления

- Частотно-регулируемые приводы INVT GOODRIVE (для CV300, CV180)
- Частотно-регулируемые приводы Schneider Altivar ATV (для BF110, SC130)
- Сеть PROFINET для связи с приводами
